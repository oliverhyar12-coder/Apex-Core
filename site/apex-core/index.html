02 / Install

Four lines on any OS.

There is no installer to download. Apex Core installs from GitHub with pipx, which gives the apex command its own isolated environment. You need Python 3.11 or newer; git is optional on Linux and macOS.

Do not run pip install apex-core. That PyPI name belongs to an unrelated project. This one is apex-core-cli and is not on PyPI yet.
Keyring support (optional)
pipx inject apex-core-cli keyring
Upgrade
pipx upgrade apex-core-cli
Uninstall
pipx uninstall apex-core-cli
Linux · bash · Arch / CachyOS
$ sudo pacman -S python-pipx # Arch / CachyOS
$ pipx ensurepath # then open a new terminal
$ pipx install "git+https://github.com/oliverhyar12-coder/Apex-Core.git"
$ apex --version

Debian / Ubuntu: sudo apt install pipx. Fedora: sudo dnf install pipx.

macOS · zsh · Apple Silicon or Intel
$ python3 -m pip install --user pipx
$ python3 -m pipx ensurepath # then open a new terminal
$ pipx install "git+https://github.com/oliverhyar12-coder/Apex-Core.git"
$ apex --version

With Homebrew you can run brew install pipx instead of the first line.

Windows · PowerShell · 10/11
PS> py -m pip install --user pipx
PS> py -m pipx ensurepath # then open a new terminal
PS> pipx install "git+https://github.com/oliverhyar12-coder/Apex-Core.git"
PS> apex --version

Install Python 3.11+ from python.org or the Microsoft Store, and git from git-scm.com (needed to install from GitHub). WSL is not required.

03 / Quick start

Three commands to a chat.

  1. 1 apex init

    Pick a provider and model. It tells you which environment variable needs your API key.

  2. 2 apex doctor --online

    Checks Python, paths, config, your key, history, git and the terminal, then tests the connection.

  3. 3 apex chat

    Interactive chat with workspace tools, in the current directory. Or use apex ask and apex task.

06 / Security model

Guard rails, not a sandbox.

An approved command runs with your user's permissions. For untrusted repositories use --read-only, or run apex in a container or VM.

Workspace containment

Tools only touch paths inside the workspace, after resolving .. and symlinks. .git and credentials files are blocked.

Approval

Edits show a diff, commands show the exact argv. Destructive or opaque commands are flagged and never auto-approved.

No shell

Commands run from an argument list with stdin closed, a timeout, an output cap and credential-like variables removed.

Not as root

If apex runs as root or an elevated Administrator, command execution is disabled.

Secrets stay out

Keys stay out of config, logs, history and errors. Known token formats are redacted before tool output reaches the model.

No .env surprises

.env files in your working directory are ignored, so a cloned repository cannot redirect your API traffic.

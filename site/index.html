02 / Apex Core

An AI agent that lives in your terminal.

Chat, ask one-off questions, or hand it a task. Apex Core reads your project, proposes edits as diffs, and runs commands only after you approve them.

  • Terminal onlyNo GUI, background service or telemetry.
  • Your providerOpenAI, Anthropic, Gemini, Mistral, Ollama and more.
  • Safe by defaultEvery edit and command asks first. No shell.
  • Cross-platformLinux, macOS and Windows 10/11.
Explore Apex Core
Linux · bash · Arch / CachyOS
$ sudo pacman -S python-pipx # Arch / CachyOS
$ pipx ensurepath # then open a new terminal
$ pipx install "git+https://github.com/oliverhyar12-coder/Apex-Core.git"
$ apex --version

Debian / Ubuntu: sudo apt install pipx. Fedora: sudo dnf install pipx. Needs Python 3.11 or newer.

macOS · zsh · Apple Silicon or Intel
$ python3 -m pip install --user pipx
$ python3 -m pipx ensurepath # then open a new terminal
$ pipx install "git+https://github.com/oliverhyar12-coder/Apex-Core.git"
$ apex --version

With Homebrew you can run brew install pipx instead of the first line. Needs Python 3.11 or newer.

Windows · PowerShell · 10/11
PS> py -m pip install --user pipx
PS> py -m pipx ensurepath # then open a new terminal
PS> pipx install "git+https://github.com/oliverhyar12-coder/Apex-Core.git"
PS> apex --version

Install Python 3.11+ from python.org or the Microsoft Store, and git from git-scm.com. WSL is not required.

v0.1.0rc1 · release candidate Not on PyPI yet, so install from GitHub. The PyPI package named apex-core is an unrelated project.

Then: apex init → apex doctor → apex chat

03 / IT topics

Notes from the bench.

T.01

Linux on the desktop

Our daily driver is CachyOS: Arch Linux underneath, pacman for everything. Apex Core installs on it with one pacman package and pipx.

T.02

Bring your own key

Use OpenAI, Anthropic, DeepSeek, Gemini, Mistral, OpenRouter or Groq. Keys stay in environment variables or your OS keyring, never in config files.

T.03

Local models

Ollama and LM Studio run on your own machine: nothing leaves it, and there is no per-token cost.

T.04

Safe automation

An agent should show you the diff and the exact command before anything happens. Read what you approve; it is the real safeguard.

T.05

Thermals & upkeep

Dust, dried thermal paste and tired fans are behind a lot of loud, hot and throttling machines. A proper clean-out often fixes it.

T.06

Back up first

Before any repair, reinstall or upgrade, copy what matters somewhere else. A five-minute backup beats a data recovery job.
